Mini-Project #1: Exploring Netflix Viewing Data

This mini-project explores Netflix viewing data from January 2023 through June 2026 to better understand what types of content attract viewers. Our analysis looks at viewing hours, popular titles, global availability, and differences between movies, TV shows, and live events. We also examine viewing patterns over time and identify limitations in the data. Based on our findings, we provide recommendations for Netflix’s 2027 content strategy.

#' Acquire Netflix What We Watched Reports
#' 
#' This function will acquire and standardize all data for MP#01
#' from Netflix. Because Netflix hosts the data files behind a CDN, we
#' are accessing the release pages and automatically extracting links to the
#' relevant files (with CDN hash). 
#' 
#' After import, files are stacked vertically and some basic cleaning is
#' performed. 

load_netflix_data <- function(){
  # Note to students: Make sure you have installed the tidyverse and fs packages
  #                   before beginning this assignment. If you aren't sure,
  #                   simply run `library(tidyverse)` at your R Console and, if
  #                   you don't see an error message, `tidyverse` has been 
  #                   installed. (Same for `fs`) If you still need to install
  #                   either package, use the `install.packages` function as 
  #                   demonstrated in class.
  library(tidyverse)
  library(rvest)
  library(readxl)
  library(fs)
  
  data_dir <- path("data", "mp01")
    
  if(!dir_exists(data_dir)){
    dir_create(data_dir, showWarnings=FALSE, recurse=TRUE)
  }
  
  NETFLIX_URLS <- list(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )
  
  download_if_needed <- function(url, local){
    if(!file_exists(local)){
      download.file(url, local, quiet = TRUE, mode = "wb")
    }
    
    return(local)
  }
    
  NETFLIX_URLS |> 
    map(read_html) |> 
    map(html_element, xpath = "//a[contains(@href, '.xlsx')]") |> 
    map_chr(html_attr, "href") |> 
    enframe("period", "url") |> 
   mutate(path = path(data_dir, paste0(period, ".xlsx")), 
          path = map2(url, path, download_if_needed), 
          data = map(path, read_excel, skip=3, na="*"), 
          data = map(data, \(x) x |> mutate(`Release Date` = as.Date(`Release Date`)))) |>
    unnest(data) |> 
    select(-url, -path) |> 
    mutate(year=str_sub(period, 1, 4), 
           half=str_sub(period, start=6), 
           period_start = make_date(year, if_else(half==1, 1, 7), 1), 
           period_end = make_date(year, if_else(half==1, 6, 12), if_else(half==1, 30, 31))) |> 
    filter(!is.na(`Hours Viewed`)) |> 
    mutate(live_event = !is.na(Runtime) & str_detect(Runtime, "\\d+:\\d+\\*"), 
           clean_time = str_remove(Runtime, fixed("*")),
           Runtime = 60 * hour(hm(clean_time)) + minute(hm(clean_time))) |>
    select(-clean_time) |>
    mutate(Runtime = coalesce(Runtime, mean(Runtime, na.rm=TRUE)), 
           .by=Title, 
           Title = stringi::stri_trans_general(Title, "Latin-ASCII"),
           Title = str_remove(Title, " // .*"), 
           Title = str_remove(Title, "[^[:ascii:]].*"), 
           Title = str_trim(Title)) |>
    filter_out(Title == "") |>
    select(year, 
           period, 
           period_start, 
           period_end, 
           Title, 
           -half, 
           Runtime, 
           Views, 
           `Hours Viewed`, 
           `Release Date`,
           `Available Globally?`, 
           live_event)
}

NETFLIX_DATA <- load_netflix_data()

Initial Data Observations

Observation 1: Average vs. Median Viewing Hours

The average is 8.27 million viewing hours, compared with a median of 1.8 million. The observations show that popular titles tend to pull the average upward. The median is a better representation of a typical title-period record because it is less affected by extremely popular titles.

Observation 2: Missing Data

Out of 61,892 records, runtime information was missing for 13,085 rows, while release dates were missing for 35,251 rows. These missing values limit our ability to accurately analyze viewing patterns based on runtime and release year.

Observation 3: Missing Movie Data

Our analysis has a limitation because the loading code only reads the first sheet of each Excel file. Since Netflix separated movies and TV shows into different sheets after 2023H1, many movie records were excluded. This explains the drop in reported title counts and affects our comparison between movies and TV shows.

Netflix 2027 Content Strategy Memo

Looking at viewing data from January 2023 to June 2026, globally available content commands a disproportionate share of total watch time, though wider availability alone does not establish that global distribution appears to be driving viewership up. The strategic goal for 2027 should be to selectively widen distribution for promising regional and mid-tier titles, while using our biggest franchise hits as direct funnels to help subscribers discover mid-tier titles and raise viewership.

Our findings on global distribution highlighted where viewing engagement is concentrated, global title is 24.6% and global hours is 51.9%. Global titles get about double the amount of viewing the share of titles by itself would suggest. Korean shows performed strongly on Netflix across multiple periods. First, King the Land was the most-watched title in the second half of 2023. Then, Squid Game: Season 2 reached the top spot in the second half of 2024 and held that ranking in the first half of 2025.

Just because globally available shows have more viewing hours doesn’t mean global availability is the reason. Netflix may spend more money promoting its biggest shows, which could explain why they attract more viewers. The data also doesn’t tell us whether these shows would have performed just as well if they had only been available in certain regions. Netflix should consider expanding regional shows globally, especially those already performing well in their home markets. However, since global availability does not guarantee higher viewing, Netflix should track whether expanding these shows actually increases viewing hours.

Netflix’s biggest franchises continue to attract significant viewing hours. Across the reporting periods, the five seasons of Stranger Things generated 5,548,500,000 hours, while the Bridgerton universe generated 4,862,800,000 hours. However, even the most-watched title in a reporting period accounts for at most 1.4% of total viewing hours. In the first half of 2026, the top 10 titles combined represented just 6.1% of viewing hours. This shows that a large portion of viewing comes from smaller titles across Netflix’s catalog.

While these numbers highlight the importance of smaller titles, the data does not show what viewers watch after finishing a popular series. Netflix should continue investing in successful franchises while testing recommendations that introduce viewers to similar, lesser-known shows. The company should then measure whether these recommendations actually increase viewing hours for those smaller titles.

To measure success, our primary engagement KPI should be increased viewing hours for smaller titles. Rather than relying on simple pre and post roll out comparisons—which are susceptible to seasonality and confounding platform shifts—Netflix should run controlled A/B tests with proper random assignment. Comparing viewing hours among users receiving targeted gateway recommendations against a comparable control group will isolate the causal effect of the recommendation engine on discovery. However, increased viewing hours alone will not prove financial return. Fully establishing commercial success will require layering in incremental localization and licensing costs alongside subscriber retention and lifetime value data, neither of which is present in the current data set.

There are a few limitations in our Netflix data that could affect the findings. First, some titles with non-English names were removed during data cleaning, which means regional content may not be fully represented. Also, most movies after the first half of 2023 are missing because the data-loading process only reads the first sheet of each report. Finally, the data set does not include production costs, subscriber retention, or revenue, so we cannot determine whether higher viewing hours would actually make these strategies profitable.
